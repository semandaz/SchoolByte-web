Here's the diagnosis of the problem and the steps to fix your website.

Diagnosis 🎯
The problem is a JavaScript infinite loop caused by the new floating-buttons.html file.

Here's the chain of events causing the crash:

Your studentdashboard.html file correctly loads and its script runs.

At the end of its script, it fetches floating-buttons.html and injects its content into the page.


Here is the error: The floating-buttons.html file also contains a script tag that tries to fetch floating-buttons.html again .

When this second script runs, it injects the content again, which triggers the script again, creating an infinite loop of fetching and injecting.

This infinite loop overwhelms the browser's network requests.

When your dashboard's main fetchStudentData function tries to get your student info from /student/dashboard, its request fails because the network is jammed by the loop. This triggers your "Cannot connect to server" error message.



How to Fix It
You need to make two edits: one to floating-buttons.html to stop the loop, and one to studentdashboard.html to clean up the code the AI added.
