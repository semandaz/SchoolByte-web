📚 How to Play:

1. Select a difficulty level from the options above

2. Click "Start Game" to begin the puzzle

3. Fill the grid so that each row, column, and 3x3 box contains all digits from 1 to 9

4. Click on a cell and then select a number from the keypad

5. Each wrong answer uses one chance

6. Use "I'm Stuck" for hints (free ones available, then pay with bytes)

7. Complete as much as possible within the time limit

8. Your grade is calculated based on accuracy and bytes earned
